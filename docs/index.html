01

关于

当前为半成品，有很多素材都使用原有素材，可能造成违规风险。

具体涉及：应用图标与启动图标里的品牌图形、桌宠「Deepy 小鲸鱼」、桌宠「鲸娘」的表情， 以及应用内的鲸鱼尾巴图形。按上游仓库 ASSETS.md 的规定，这些素材不在 AGPL-3.0 的授权范围内， 版权归原作者所有，以修改版身份再发布时应当替换成自己的素材。

我们暂时没有完成替换，公开发布这一状态是我们考虑不周。在此向原作者与使用者致歉。 自有素材已在制作，替换完成后会重新发版，并在版本说明中明确写出替换范围。

另外两点也需要提前说明。第一，这是公开测试版本，功能与稳定性仍在完善，不建议当作日常主力工具。 第二，本次改动只在构建环境中完成编译与签名校验，没有在真机上做完整回归， 其中审批浮层的触摸修复尤其需要真机确认。遇到问题请通过 Issue 反馈。

DSH Pro 是手机端 DeepSeek Harness 的二次开发版本，代码基线取自上游 DSH Go 1.0.11。 它的目标不是做一个远程聊天客户端，而是让完整的 agent 运行时在手机上本地跑起来： 文件读写、命令执行、联网搜索、插件加载都由手机内的引擎完成，不依赖电脑。

界面
Flutter 原生界面会话、审批、用量、设置与插件市场；像素级对齐，深浅色跟随系统。
客户端
纯 Dart 实现HTTP 与 SSE 连接、多路复用、会话管理；不经过 WebView。
运行时
PRoot 内的 Linux 环境Ubuntu 基础镜像、Node 24 与打过补丁的 DSH 引擎，随安装包一起分发。
模型
DeepSeek 官方与自定义渠道支持 OpenAI Completions、Anthropic Messages、Responses 三种协议，填写 Base URL 后可自动拉取模型列表。

这个版本与上游的主要差异集中在四件事：品牌改为 DSH Pro；用量面板显示本对话累计消费金额； 图标与启动动画增加液态玻璃质感；合并了上游尚未合并的审批浮层触摸修复。 插件市场另有独立的兼容版本号处理，避免因为版本号变小而误判插件不支持。

02

本次更新

品牌

应用显示名改为 DSH Pro，桌面图标、最近任务、通知与系统设置中保持一致，中英文及区域语言资源同步。 应用内字标与启动画面一并更新。界面文案做了全量清扫，中文 69 处、英文 74 处涉及旧名称的条目全部改完； 确需保留的外部指代，例如上游项目名与原作者姓名，不受影响。Android 原生字符串、分享落地页、 对话导出网页同步更新，导出文件内嵌的页面已重新生成。

关于页

新增「DSH Pro 作者」区块，GitHub 链接指向本仓库所有者；保留「原作者」区块， 其中包含原作者的 B 站、X 与 GitHub 三个入口，用于满足上游的署名要求。 版本、检查更新、开源许可与免责声明保持原有结构。

对话计费

写入 DeepSeek 官方人民币单价，覆盖 deepseek-flash 与 deepseek-v4-pro， 含缓存命中、缓存未命中与输出三项。按北京时间自动区分高峰与空闲时段： 工作日 09:00 至 12:00、14:00 至 18:00 为高峰，其余时段与周末按空闲价计算。 法定节假日没有单独建模，该时段按高峰价估算，因此结果只会偏高，不会偏低。

图标与启动动画

默认图标与「霜白」自适应图标增加液态玻璃质感：左上方向的镜面高光带、光角处的折射光晕、 远边的冷色反光。图层用矢量渐变实现，不同分辨率下表现一致。「夜幕」与「墨黑」两个变体保持不变。 启动动画的扫光由 34% 宽度、0.26 亮度调整为 42% 宽度、0.34 亮度，扫过时更接近液体反光。

审批浮层触摸修复

合并上游修复：底部升起的审批卡不再因为系统遮挡标志而丢弃全部触摸。此前在横屏、切换前后台、 存在其他悬浮层时，会出现按钮点不动、没有涟漪、倒计时走完按拒绝处理的现象。 改动涉及四个文件：审批浮层卡片、输入策略判定、无障碍控制浮层、桌宠气泡应答键。

安全防护没有放宽：延迟启用、输入注入拦截、虚拟设备与可疑笔画判定、TalkBack 判定都保持不变。

插件兼容

插件市场以 dshGo.minApp 判断应用版本是否满足要求。版本号改为 0.1.3 之后， 所有要求 1.0.x 的插件都会被误判为不支持。为此新增独立的兼容版本号 1.0.11， 插件门槛按该值判断，界面与更新仍显示 0.1.3。要求不超过 1.0.11 的插件可以正常安装。

03

安装

  1. 下载 DSH-Pro-0.1.3-arm64-release.apk。
  2. 在系统设置中允许本次安装来源安装应用。
  3. 安装后首次启动会解包内置运行环境，耗时与设备性能有关。
  4. 覆盖安装需要与旧版本使用同一签名。本版本使用 CN=DSH POR 证书，可以覆盖此前的同签名构建。

安装包只包含 arm64-v8a。Android 版本低于 8.0 的设备无法安装。 包名刻意保持为 io.github.ccch1mneyyy.dsh_app 未做改动，目的是支持覆盖安装。
