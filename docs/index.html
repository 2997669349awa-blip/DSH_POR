授权风险提示

当前为半成品，有很多素材都使用原有素材，可能造成违规风险。

具体涉及：应用图标与启动图标里的品牌图形、桌宠「Deepy 小鲸鱼」、桌宠「鲸娘」的表情， 以及应用内的鲸鱼尾巴图形。按上游仓库 ASSETS.md 的规定，这些素材不在 AGPL-3.0 的授权范围内， 版权归原作者所有，以修改版身份再发布时应当替换成自己的素材。

我们暂时没有完成替换，公开发布这一状态是我们考虑不周。在此向原作者与使用者致歉。 自有素材已在制作，替换完成后会重新发版，并在版本说明中明确写出替换范围。

DSH Pro 是手机端 DeepSeek Harness 的二次开发版本，代码基线取自上游 DSH Go 1.0.11。 它不做远程聊天客户端，而是让完整的 agent 运行时在手机上本地跑起来，不依赖电脑。

这是公开测试版本，功能与稳定性仍在完善，不建议当作日常主力工具。 本次改动只在构建环境中完成编译与签名校验，没有在真机上做完整回归， 其中审批浮层的触摸修复尤其需要真机确认。

运行结构

  • 界面 Flutter 原生界面。会话、审批、用量、设置与插件市场，深浅色跟随系统。
  • 客户端 纯 Dart 实现。HTTP 与 SSE 连接、多路复用、会话管理，不经过 WebView。
  • 运行时 PRoot 内的 Linux 环境。Ubuntu 基础镜像、Node 24 与打过补丁的 DSH 引擎，随安装包一起分发。
  • 模型 DeepSeek 官方与自定义渠道。支持 OpenAI Completions、Anthropic Messages、Responses 三种协议。

03 / INSTALL

安装

四步完成，首次启动
需要解包运行时。

  1. 下载安装包 选择 arm64 版本，文件名 DSH-Pro-0.1.3-arm64-release.apk。
  2. 允许安装来源 在系统设置中允许本次安装来源安装应用。
  3. 等待首次启动 启动后会解包内置运行环境，耗时与设备性能有关。
  4. 覆盖安装 需要与旧版本使用同一签名。本版本使用 CN=DSH POR 证书，可以覆盖此前的同签名构建。
